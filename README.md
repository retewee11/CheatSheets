## 📖 Descripción General

Este espacio está diseñado para centralizar y organizar de forma eficiente comandos esenciales, payloads y metodologías que optimizan el trabajo en entornos reales y laboratorios (*Hack The Box, TryHackMe*).

### ⚡ Características:
* **Orientado a la Agilidad**: Sin rodeos teóricos, enfocado puramente en comandos accionables.
* **Formato Limpio**: Estructurado en bloques listos para copiar y pegar rápidamente.
* **Seguridad y OPSEC**: Anotaciones sobre firmas y nivel de ruido de cada técnica.
